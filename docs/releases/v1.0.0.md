## Proof boundary

This proves publication, source download and isolated portable installation from
the GitHub release. It does not prove npm publication, client marketplace
distribution, native client loading, clean-session routing, production behavior
or buyer usefulness. Those levels remain separate in
[the compatibility matrix](../COMPATIBILITY.md).

Rollback for an installed copy is to remove only links created from this source
or restore the project's previously reviewed Git ref. There is no earlier stable
NoBrainer Tech Skills release to pin automatically.
