## What changed

- Ordinary tasks now expose one short Progress checklist instead of the full
  internal execution state. Long-running or coordinated work can still use a
  durable canonical ledger with identity, ownership, checkpoints, evidence,
  retries and rollback.
- Scope freezes expected files, proof, untouched work, minimum solution, test
  decision and clean completion before non-trivial writes.
- Local deterministic failures begin by reproducing the documented command
  from the repository root; current or uncertain remedies retain the research
  gate. Repository evidence, not owner ceremony, settles implementation details.
- Ultra now loads the canonical specialist body and required references before
  planning a specialist-owned stage; routing-table memory is not sufficient.
- The Codex installer targets the documented shared `.agents/skills` location,
  and canonical explicit invocation is `$nobrainer-ultra`.
- Public-repository automation is fetch-only. Commit, push, PR and merge remain
  human-owned, with public commit guards for backup paths and automated actors.
- Every current public head and release tag was checked for the exact retired
  backup identity and trailer. Affected refs were rewritten with
  expected-old-SHA leases and independent source-tree parity; unrelated
  historical authors and committers were preserved. GitHub-managed historical
  pull-request refs are not writable.

## Runtime boundary

The accepted Codex evidence used an isolated repo-scoped install, disabled
same-name global copies and invoked the canonical skill explicitly. Final-hash
Luna runs used `max` reasoning, requested priority/fast service, passed pressure
and stable local-error cases, loaded Autoimprove, and completed a real isolated
two-file implementation with independent tests and diff readback. The CLI did
not expose the response service tier, so this does not claim a server-side fast
tier was verified.

The alias-only control did not load the canonical skill body and failed. The
mechanical non-trigger control also failed because Luna claimed a simulated edit
without loading Ultra; no broad Ultra trigger was added for that model-level
failure. Claude Code first hit an authentication blocker, then passed an
owner-authenticated isolated plugin run that loaded final Ultra and canonical
Autoimprove. Explicit runtime is verified; automatic routing and distribution
are not.

The bounded long-run compression experiment produced shorter development
responses, but its final paired check also included a different Ultra routing
rule. That source drift invalidated causal comparison of the compact reference,
so no candidate was promoted, the original reference was retained and the
sealed cases were not reused.
