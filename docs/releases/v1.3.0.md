## What changed

- Ordinary tasks now expose one short Progress checklist instead of the full
  internal execution state. Long-running or coordinated work can still use a
  durable canonical ledger with identity, ownership, checkpoints, evidence,
  retries and rollback.
- Scope freezes expected files, proof, untouched work, minimum solution, test
  decision and clean completion before non-trivial writes.
- Local deterministic failures begin with repository evidence; current or
  uncertain remedies retain the research gate.
- The Codex installer targets the documented shared `.agents/skills` location,
  and canonical explicit invocation is `$nobrainer-ultra`.
- Public-repository automation is fetch-only. Commit, push, PR and merge remain
  human-owned, with public commit guards for backup paths and automated actors.
- Every current public head and release tag was checked for the exact retired
  backup identity and trailer. Affected refs were rewritten with
  expected-old-SHA leases and independent source-tree parity; unrelated
  historical authors and committers were preserved. GitHub-managed historical
  pull-request refs are not writable.
