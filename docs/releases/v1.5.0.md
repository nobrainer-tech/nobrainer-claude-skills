## What changed

- `nobrainer-ultra` now makes a public-surface decision part of every scope:
  update affected README, docs, templates, assets and flow, or record
  `PUBLIC_SURFACE: NOT_NEEDED` with a reason. Public contract, routing and
  workflow changes use the full lifecycle and require fresh SVG and README
  Mermaid readback.
- The quick path is limited to edits with no public contract, routing, workflow
  or portfolio impact; scope expansion escalates to the full lifecycle.
- Root workflow instructions and the routing reference carry the same rule.
- README's Mermaid flow and `assets/nobrainer-workflow.svg` show the quick path
  and the public-surface coherence gate.
- The v1.4.0 publication gap is recorded in
  [`v1.4.0-publication-readback.md`](v1.4.0-publication-readback.md) instead of
  being silently rewritten.

The candidate keeps exactly fifteen skills. No automated public commit, push,
PR, merge, tag or publication is part of the repository's scheduled jobs.
