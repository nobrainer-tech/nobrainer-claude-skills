## What changed

- `nobrainer-ultra` now names a quick path for one coherent, reversible small
  change. It still requires local inspection, a nearest check, diff/status
  readback and escalation when scope, risk, proof or an owner gate expands.
- `nobrainer-writing` uses one environment block for bugs and comments with the
  environment name, exact URL and user used. Bug reports require an explicit
  `Description`, omit the separate `Impact` field and call UI screenshot or MP4
  proof `Evidence`.
- API request/response and database query/result proof remain separate and
  copyable. The public bug template and regression tests follow the contract.

The candidate keeps the existing fifteen-skill inventory and the previous
`v1.3.1` release remains the rollback source until a fresh publication readback
is complete.
