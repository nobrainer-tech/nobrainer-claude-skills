This is the release evidence for the whole-portfolio hardening change. The
behavioral owner was `nobrainer-autoimprove`; the companion edits tighten Ultra,
Build, Dispatcher and Sessions routing, context receipts and concise operator

## Pareto loop

The first failed candidates were not treated as permission to stop. Rounds 13–18
closed the largest demonstrated gap in sequence: evaluator integrity, literal
scope/timing/closed-set wording, range compliance, judge calibration and exact
counting. Invalid rubrics, source drift, infrastructure shutdowns and hard-range
failures were recorded as invalid/rejected rather than averaged into a score.
Each new attempt used a fresh holdout and re-baselined comparison. Final5 was the
first valid promotion candidate.
