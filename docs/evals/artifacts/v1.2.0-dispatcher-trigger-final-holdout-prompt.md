## Ownership and stop contract

- Ultra owns intent, requirements, the complete execution map and lifecycle.
- Team owns minimum roles and capability sources only after an approved map;
  explicit Team invocation may report a missing map but cannot invent one.
- Dispatcher owns scheduler inspection, ready-set selection, ordering,
  backpressure and retry scheduling for already-defined units.
- An explicit Dispatcher invocation is a discovery trigger. For a one-unit map,
  Dispatcher owns only the requested scheduler inspection, returns
  `NOT_NEEDED`, and leaves the work product in MAIN.
- Sessions owns exact session identity, transport, lease and receive-audit.
- Assigned methods or workers own work products. Dispatcher never implements,
  transports, audits raw reports, designs roles or finally accepts evidence.
- A blocked unit can be reconsidered only when cited new evidence or a changed
  condition changes its blocker. Remaining retry budget alone is insufficient.
- No successor is released before all its predecessors are independently
  `ACCEPTED`.
