## Case D

Multiple agents can reduce elapsed time when tasks are genuinely independent and each result can be checked on its own, but that benefit disappears when they contend for the same mutable files or when coordination and review cost more than the work itself. A single coherent change should therefore stay with one agent, while parallel sessions should be reserved for bounded work with disjoint ownership and explicit acceptance checks.
