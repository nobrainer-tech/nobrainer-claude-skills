## Case B

Title: [Bug] Job 7 is marked completed with zero output

Summary: Job 7 is marked `completed` even though its output count is zero.

Impact: The job history reports completion for a job that produced no output.

Environment: staging, release 1.3.1
URL: https://example.test/jobs/7

Steps to reproduce:
1. Open the URL.
2. Open job 7.
3. Compare the status with the output count.

Current behavior: Job 7 is marked `completed` with `output_count=0`.

Expected behavior: A job with zero output must not be shown as completed.

Evidence:

Query:
```sql
SELECT status, output_count FROM jobs WHERE id = 7;
```

Result:
```text
status=completed, output_count=0
```

## Case D

Title: [Bug] Order confirmation returns HTTP 502

Summary: The order confirmation API returns an error instead of confirming the order.

Impact: The API does not report the order as confirmed.

URL: https://example.test/api/orders/42/confirm

Steps to reproduce:
1. Send the request shown in Evidence.
2. Inspect the response.

Evidence:

Request:
```http
POST https://example.test/api/orders/42/confirm
Content-Type: application/json
```

```http

Content-Type: application/json

{"error":"upstream unavailable"}
```
