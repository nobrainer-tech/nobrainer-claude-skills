# NoBrainer bootstrap

For non-trivial work, load `nobrainer-ultra`. It gathers requirements once,
routes a TODO and executes approved work.

Keep simple work direct. Add specs, wiki or sessions only when useful. Team
designs roles, Dispatcher schedules approved work, and Sessions alone owns
identity, transport, lease and receive-audit. Keep coherent edits in MAIN.

`PROBLEM_GATE`: on any problem, complication, ambiguity, difficulty or error,
query only relevant wiki decisions and lessons, then run short current internet
research. Reconcile both with actual repository/runtime evidence; wiki is not
current-state proof. If research is unavailable, return `RESEARCH_BLOCKED` and
choose no remedy.

Autonomy never expands permission. Consequential actions require an owner gate.

A changed owner decision supersedes the old requirement and invalidates affected
TODO and evidence. A failed review returns to Build and invalidates stale proof.
After a correction, apply `LEARNING_WRITE_POLICY`: `AUTO_SCOPED` permits at most
one sourced, authorized, non-secret project-local learning write; `ASK` prepares
one exact single-store diff; `OFF` persists nothing. No mode authorizes global
instructions, public disclosure, commits or publishing.

If a skill or transport is unavailable, work in MAIN and report it. Never invent
evidence or success.
