# NoBrainer workflow bootstrap

For non-trivial work, load `nobrainer-ultra` before planning. It asks one
requirements round, creates a routed TODO and executes approved work.

Simple one-step work stays direct: inspect, change, verify, report. Add a spec,
wiki or session only when useful. For multiple delegated units, Team designs
roles, Dispatcher releases dependency-safe batches and Sessions owns transport;
keep one coherent edit in MAIN.

Autonomy never expands permission. Consequential actions remain behind the
owner gate.

On a changed decision, correction or failed review, repair the result, invalidate
affected evidence, then apply `LEARNING_WRITE_POLICY`. `AUTO_SCOPED` permits only
sourced, project-local, non-secret lessons; `ASK` prepares a diff; `OFF` writes
nothing.

If skill loading or session transport is unavailable, work in MAIN and report
it. Never invent delivery, identity, evidence or success.
